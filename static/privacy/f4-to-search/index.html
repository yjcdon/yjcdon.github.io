F4 to Search Privacy Policy

Updated November 19, 2026

When you select text and press F4, the extension reads the current selection and opens Google Search with that text as the query. The extension excludes password fields. Google receives the query and handles it under its privacy policy (https://policies.google.com/privacy). The extension does not store a search history or send selections to the extension developer.

The extension uses user data in accordance with the Chrome Web Store User Data Policy, including the Limited Use requirements.
